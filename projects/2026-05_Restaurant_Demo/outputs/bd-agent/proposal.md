# Propunere — Restaurant Demo

## Rezumat

Restaurant Demo pierde timp la orele de varf prin copiere manuala a comenzilor si actualizare manuala de stoc. Propunem un MVP de 4 saptamani care centralizeaza comenzile, verifica disponibilitatea produselor, pregateste confirmarile si produce un raport zilnic.

## Ce Livram

- Tabel central de comenzi in Google Sheets.
- Catalog produse cu praguri minime de stoc.
- Validare comenzi vs. stoc.
- Alerte low-stock pentru operator.
- Confirmari Gmail-ready.
- Raport zilnic: produse vandute, exceptii, stoc scazut.
- SOP si ghid pentru operator.

## Ce Nu Include Faza 1

- Trimitere autonoma WhatsApp.
- Plati sau comenzi automate catre furnizori.
- Runtime LLM platit.
- Migrare istorica extinsa.

## Timeline

| Saptamana | Livrabil |
|-----------|----------|
| 1 | Catalog, reguli business, workflow capture |
| 2 | Backend scripts si structura Google Sheets |
| 3 | Operator view, SOP si testare interna |
| 4 | QA, handover si plan monitorizare |
