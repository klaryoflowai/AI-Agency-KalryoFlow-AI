# 💼 Modelul de Business & Strategie

## Profilul Companiei
- **Tip:** Agenție de automatizare AI pentru IMM-uri
- **Model livrare:** Proiecte custom per client
- **Industrii:** Flexibil — în funcție de clienții obținuți
- **Fondator:** CEO/PM non-tehnic
- **Budget lansare:** Sub 10.000€ (bootstrap)

---

## Propunerea de Valoare
> IMM-urile nu au nevoie de tehnologie complexă.
> Au nevoie de cineva care **traduce AI în rezultate business concrete.**

---

## Modelul de Revenue

### Tipuri de Proiecte
| Tip | Descriere | Preț estimat |
|-----|-----------|--------------|
| Small | Automatizare simplă (1-2 procese) | 1.500 – 3.000€ |
| Medium | Suită de automatizări + integrări | 3.000 – 8.000€ |
| Large | Sistem complet custom | 8.000 – 20.000€ |
| Retainer | Mentenanță + îmbunătățiri lunare | 500 – 2.000€/lună |

### Target Revenue
- Luna 1-2: 0€ (construire sistem + validare)
- Luna 3: primul proiect ~2.000€
- Luna 6: 2-3 proiecte/lună = 5.000-10.000€
- Luna 12: retainere + proiecte = 15.000-25.000€/lună

## Procesul de Vânzare (Sales Flow)

```
1. LEAD IDENTIFICAT
   └── BD Agent generează propunere inițială

2. DISCOVERY CALL
   └── Tu (CEO) vorbești cu clientul ~45 min

3. EVAL AGENT
   └── Analizează brief → SOW + estimare cost

4. PROPUNERE COMERCIALĂ
   └── BD Agent draftuiește → tu trimiți

5. CONTRACT & AVANS (30-50%)
   └── Proiectul intră în sistem

6. EXECUȚIE
   └── Agenții lucrează → tu supervizezi

7. LIVRARE & SOLD FINAL
   └── QA Agent verifică → tu prezinți clientului

8. FOLLOW-UP
   └── Client Success Agent menține relația
```

---

## Avantaj Competitiv
1. **Viteză** — agenții lucrează în paralel, nu secvențial
2. **Consistență** — același proces pentru fiecare proiect
3. **Scalabilitate** — poți gestiona 5+ proiecte simultan
4. **Documentație** — fiecare proiect e perfect documentat automat

## Politica de Cost LLM
- MVP intern: Codex și Claude Code sunt operatori, deci nu folosim API LLM plătit pentru execuția agenției.
- Proiect client cu automatizare unattended: API-ul LLM se estimează separat și se include în ofertă sau retainer.
- Niciun cost LLM recurent nu rămâne ascuns în marja agenției.
- Propunerile comerciale trebuie să marcheze clar: setup fee, mentenanță și cost operațional estimat.

## Fazele de Lansare

### Faza 1 — Luna 1-2 (Validare)
- Construiești Eval Agent + Ops Agent
- Iei primul client (poate gratuit sau la preț redus)
- Livrezi și validezi că sistemul funcționează

### Faza 2 — Luna 3-4 (Sistematizare)
- Adaugi BD Agent + QA Agent
- Documentezi fiecare proiect ca template refolosibil
- Începi să ceri prețul complet

### Faza 3 — Luna 5-6 (Scalare)
- Orchestratorul leagă tot automat
- Gestionezi 3-5 proiecte simultan
- Angajezi primul om (junior tehnic sau account manager)
