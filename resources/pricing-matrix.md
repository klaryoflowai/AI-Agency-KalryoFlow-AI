## Runtime API Client-Side
Costul LLM runtime nu intră în orele de implementare. Se estimează separat:

```
cost_lunar_estimat = volum_lunar * cost_per_run + buffer 20%
```

Regulă: niciun runtime LLM plătit nu se promite fără aprobare CEO și includere în ofertă.
